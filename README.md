# Kaka & Chui

An Android game that teaches Swahili to children aged 3–6. Six learning modules — vowels, words, numbers 1–10, numbers 11–20, shapes and colours — with flash cards, quizzes, memory match and sound match, plus stars, XP, coins and daily streaks.

The Gradle project lives in [`KakaRemake/`](KakaRemake). It is a single-module Jetpack Compose app (`:app`, application ID `com.game254studios.kakaandchui`) built with AGP 8.7.3 and Kotlin 2.1.0.

## Build and run

You'll need JDK 17 or newer, Android SDK Platform 35, and an Android device or emulator running Android 7.0 (API 24) or later.

Follow the [run instructions](run_instructions.md) to build and launch the debug app locally.
