# Play Store Graphics Requirements

## Feature Graphic (1024×500)
- **File**: `feature-graphic.png`
- **Depicts**: Kaka (eagle) and Chui (leopard) characters surrounded by colorful flash cards showing vowels, numbers, shapes, and colors. Background should feature vibrant East African landscape colors (greens, oranges, blues). App title "Kaka & Chui: Learn Swahili" prominently displayed. Playful, child-friendly style with bright, warm colors.

## App Icon (512×512)
- **File**: `icon.png`
- **Depicts**: Kaka (eagle) and Chui (leopard) together in a friendly pose. Bold, simple design that reads well at small sizes. Bright background color (yellow or orange). No text — the characters should be the focus. Rounded corners per Google Play guidelines.

## Phone Screenshots (1080×1920 or 16:9)
- **Directory**: `screenshots/phone/`
- **Required**: Minimum 2, recommended 8
  1. **Welcome/Home screen** — Shows the main menu with all 6 learning modules
  2. **Flash Card (Learn Mode)** — A vowel or number flash card with audio button
  3. **Quiz Mode** — Multiple choice question with colorful answer options
  4. **Memory Match** — Card grid mid-game showing matched and unmatched pairs
  5. **Sound Match** — Audio prompt with picture selection grid
  6. **Progress/Achievements** — XP level, coins, streak, and achievement badges
  7. **Star Rating** — Quiz completion screen with 3-star rating animation
  8. **Parental Gate** — Settings screen showing parental controls

## Tablet Screenshots (1920×1200 or 16:10)
- **Directory**: `screenshots/tablet/`
- **Required**: Minimum 2, recommended 4–8
- Same scenes as phone screenshots, optimized for tablet landscape/portrait layout

## Design Guidelines
- Use actual in-app screenshots with device frames
- Add short captions/callouts highlighting key features
- Maintain consistent color palette across all graphics
- Text should be large and readable at Play Store thumbnail sizes
- Include both English and Swahili text where appropriate
